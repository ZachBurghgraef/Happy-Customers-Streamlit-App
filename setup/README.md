# Version Requirements and Setup

## Python Version Used

Python 3.13.13

## python packages

To install all necessary python packages to use this project one should use a virtual environment. To create a virtual environment one could use the built in python module by running:

`python -m venv .venv`

This will create a virtual environment that is named ".venv".

To activate the virtual environment, run:

Unix:

`source .venv/bin/activate`

Windows:

`.venv\Scripts\activate`

To install the required packages:

`pip install -r setup/requirements.txt`
